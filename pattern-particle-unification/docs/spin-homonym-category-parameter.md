## 1. The problem

"Spin" means different things in 3D (Standard Model) and 2D (condensed matter). A diagram calculus (ZX) that writes one crossing symbol for both silently inherits one of the two meanings. This is not a notation problem — it is a *semantic-target* problem: the diagrams do not distinguish spin by themselves; the category does.

## 3. The default is the 3D import

Vanilla ZX assumes the involutive crossing: wires pass through each other, two crossings cancel (Reidemeister move holds). An anyon's braid (σ² ≠ 1) cannot be represented in the standard calculus without extension. The spin homonym is a semantic-target problem: the calculus defaults to 3D because its semantics is Hilbert-space-fixed.
