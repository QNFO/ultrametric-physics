# CMB Higher n-Point Functions: p-adic Signatures Beyond the 2-Point Function

**WBS:** `QNFO.UMP.007` · **Program:** Ultrametric Physics (`QNFO.UMP`) · **Status:** Phase 0 (Init)

## Overview

Planck 2018 constrains p-adic log-periodic oscillations in the CMB 2-point function
to <0.3% amplitude (published null, RQ-002). This project extends the ultrametric
cosmology program to **higher-order statistics**: do the CMB bispectrum (3-point) and
trispectrum (4-point) carry p-adic signatures below the 2-point sensitivity threshold?

Deliverables: a falsifiable formalism for p-adic non-Gaussian shapes, a test against
public Planck 2018 data, and a quantified constraint — detection or an upper bound.
